# Sundaram Mishra — Portfolio

A personal portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

## Run locally

```bash
corepack pnpm install
corepack pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
corepack pnpm build
```

## Deploy to Vercel

1. Push this repository to GitHub.
2. In Vercel, choose **Add New → Project** and import
   `sundarammishra2026/sundaram-portfolio`.
3. Keep the detected Next.js settings and select **Deploy**.

The portfolio content is based on Sundaram Mishra's supplied resume. The
original project template is from
[shakyasagar166/shivam_portfolio](https://github.com/shakyasagar166/shivam_portfolio);
the MIT license is retained in [LICENSE](./LICENSE).

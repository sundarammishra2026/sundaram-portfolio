# Contributing

This repository contains Sundaram Mishra's personal portfolio. For corrections
or suggestions, open an issue in this repository or contact
[msundaram640@gmail.com](mailto:msundaram640@gmail.com).

Before submitting a pull request, run:

```bash
corepack pnpm lint
corepack pnpm build
```
